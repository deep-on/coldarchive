Backups are still your job

We won't be vague about this. ColdArchive is a tool that moves files, and every tool that moves files carries risk. Disks fail, cloud accounts get locked, and we may have bugs we haven't found.

This app is not a backup. Keep using Time Machine or whatever you use. That said, here's what we've built so the risk isn't yours alone:

  • You see the list first, and nothing is touched until you say so.
  • Turn on rehearsal and it only observes for a few days — any file used even once drops off the list.
  • A restore script is placed in the archive folder. Everything goes home without this app, without internet, without even the Mac you started on.
  • Files inside git repositories, hidden files, and any folder you exclude were never candidates.
