一度買えば、ずっと使えます。サブスクリプションでも自動更新でもありません。ただし、このアプリはお客様のファイルを移動します。だからこそバックアップは引き続きお客様の役目だという点は、はっきりさせておきます。以下にその理由と、それでも安全でいられるよう用意したしくみを書きました。

何を買うことになるのか

ColdArchive をご購入いただくと、期限のない使用権が得られます。

  • 個人ライセンス — ご本人が使う Mac 1 台。
  • ファミリーライセンス — 同じ世帯の Mac 3 台まで。
  • サブスクリプションではありません。お支払いは一度きりで、再請求されることはありません。
  • 同じメジャーバージョン内の更新（1.0 → 1.4 など）は無料です。次のメジャーバージョン（2.0 など）は有償アップグレードになる場合があります。そのときは事前にお知らせします。

返金

決済は Paddle が処理しており、この購入における法律上の販売者は Paddle です。そのため返金は、私たちではなく Paddle に申請し、Paddle が判断します。14 日以内にお申し出いただければ、私たちはその申請を支持します。これまで反対したことは一度もありません。お住まいの国の法律が別途の撤回権を定めている場合もあり（EU・EEA・英国は 14 日、韓国は 7 日）、そちらのほうが有利であれば、その権利が優先します。

こちらからどうぞ：paddle.net — もしくは support@deepon.kr までメールをいただければ、こちらで手続きします。

バックアップは引き続きお客様の役目です

ここは曖昧に書きません。ColdArchive はファイルを移動する道具であり、ファイルを移動する道具にはどれもリスクが伴います。ディスクは壊れることがあり、クラウドのアカウントはロックされることがあり、私たちがまだ見つけていない不具合があるかもしれません。

このアプリはバックアップではありません。Time Machine など、お使いのバックアップは続けてください。そのうえで、リスクをお客様だけに負わせないために、次のものを用意しています。

  • 移動する前にまず一覧でお見せします。お客様が承認するまで、どのファイルにも触れません。
  • リハーサルをオンにすると、数日のあいだ観察するだけになります。その間に一度でも使われたファイルは対象から外れます。
  • 保管先に復元スクリプトを一緒に置きます。このアプリがなくても、インターネットがなくても、最初の Mac がなくても、すべて元の場所に戻せます。
  • git リポジトリ内のファイル、隠しファイル、除外指定したフォルダは、はじめから対象外です。
